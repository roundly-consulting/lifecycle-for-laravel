# Lifecycle for Laravel

Status lifecycles for Eloquent models: guarded named transitions, limits and quotas, expiry and
scheduled transitions, rollbacks and an append-only history.

## Requirements

- PHP ^8.4
- Laravel 12.x or 13.x

## Installation

```bash
composer require roundly-consulting/lifecycle-for-laravel
```

The full usage documentation is written alongside the implementation.

## Testing

```bash
composer test
```
